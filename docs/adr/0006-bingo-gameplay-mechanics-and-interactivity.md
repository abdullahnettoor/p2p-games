# BINGO Gameplay Mechanics, Interactivity, and Rematch Lifecycle

To maximize engagement and minimize network overhead, BINGO boards support both manual placement and one-tap randomization with a 30-second turn timer. Interactivity utilizes zero-asset synthesized Web Audio API and transient peer-to-peer emoji reactions. Completed matches support zero-reconnection instant rematches over the existing WebRTC DataChannel.
